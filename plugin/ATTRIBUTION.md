# Icon attribution

## Icons in this plugin

Every icon this plugin ships comes from an open, redistributable source:

- **generic** (plain cloud, database, server and similar shapes): hand-drawn for this
  project, MIT license.
- **open**, brand marks: [Simple Icons](https://simpleicons.org), CC0-1.0.
- **open**, `kind-*` category icons: [Lucide](https://lucide.dev), ISC license.
- **data** (data-platform logos): the [SVG Logos](https://github.com/gilbarbara/logos) set
  by Gil Barbara (CC0-1.0), Simple Icons (CC0-1.0) and Lucide (ISC).

To fit the whiteboard's image format, each icon was rewritten with single quotes and
escaped `#` and `%` characters. Ten data logos that used color gradients (among them
DynamoDB, Fabric, Flink, Grafana, Kinesis, Power BI, Redshift and SAP) were flattened to one
color. The other drawings are unchanged.

## Official cloud icons (not included)

This plugin doesn't include the AWS, Azure or Google Cloud architecture icons. Each person
who wants them gets their own copy from the vendor, after agreeing to the vendor's terms:

- AWS: https://aws.amazon.com/architecture/icons/
- Azure: https://learn.microsoft.com/en-us/azure/architecture/icons/
- Google Cloud: https://cloud.google.com/icons

The import-icons skill converts those copies on the person's own computer so the whiteboard
can draw them. Converting changes them: CSS styles become plain attributes, color
gradients become one flat color, clip paths are removed, and icons the whiteboard can't draw are left out. Imported icons stay under
each vendor's terms.
