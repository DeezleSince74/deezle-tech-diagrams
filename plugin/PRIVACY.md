# Privacy

Deezle Tech Diagrams is a skills-only plugin. It is instructions and a set of open
icons stored as JSON (JavaScript Object Notation) files. It has no server and ships no code.

## What it collects

Nothing. The plugin has no analytics, no tracking and no accounts. It sends nothing to the
author or to anyone else.

## Network requests

None. The plugin never downloads anything. If you want the official AWS, Azure or Google
Cloud icons, you download the zip yourself from the vendor's own page and hand Claude the
file.

## What it stores on your computer

Only icons you choose to import. They are saved in `~/.deezle-tech-diagrams/icons`
(the `.deezle-tech-diagrams/icons` folder in your home folder). Ask Claude to
*"remove the imported icons"*, or delete that folder, to remove them.

## Your boards

The diagrams you draw are Claude Whiteboards. They live in your Claude account, under
Anthropic's privacy policy, not with this plugin.
